Import ward boundaries

Attach real ward polygon shapes to existing wards, matched by name. Requires you to be logged in as an authorized admin.

GeoJSON format

Upload a ward map (a GeoJSON file, e.g. from bharatlas.com or the municipal corporation). Each ward's name in the file (a property such as Ward Name, ward_name or name) is matched, ignoring capitals, to a ward already added in the chosen area.

  • This only updates wards that already exist — it never creates new ones. Add the ward first via the jurisdiction CSV importer.
  • A ward name in the file with no matching local unit is reported as "unmatched," not an error.
  • Re-uploading the same file safely overwrites the polygon on each matched ward.
