Copies of GrievIQ

Web addresses where a copy of GrievIQ's pages or server has been seen running. GrievIQ's own addresses are never listed.

A copy reports only its web address, the first part of the page address, the country and how often: no person, IP address or citizen data. Someone who knows the check is there can remove it, so an empty list doesn't prove there are no copies. If you find one, save this page as a PDF and talk to your lawyer.
