Import jurisdiction data

Bulk-load MP/MLA/municipal body/ward structure from a CSV. Requires you to be logged in as an authorized admin.

CSV format

One row per ward or village. Required columns: mp_constituency_name, mla_constituency_name, local_unit_name, unit_type (RURAL or URBAN). Everything else is optional but recommended.

  • MP, MLA, and municipal body rows that repeat across many wards are only created once — matched by name.
  • Re-uploading the same CSV updates existing rows instead of duplicating them.
  • localities should be a semicolon-separated list, e.g. Hazratganj; Ashok Marg.
  • For villages, an optional block column helps citizens find them.
  • You see what will happen before anything is saved: check the file first, then import.
