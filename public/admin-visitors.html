How this is counted: each citizen page sends one anonymous signal when it opens. There are no cookies and nothing is stored on the visitor's device. Network addresses are never stored: a visitor is recognised for one day only, by a one-way code made with that day's secret, which is deleted when the day ends. Places are city level, as reported by Cloudflare. Browsers set to "Do Not Track" or "Global Privacy Control" are not counted. Staff pages are not counted.
